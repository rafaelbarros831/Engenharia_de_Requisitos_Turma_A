## Trabalhos e projetos da disciplina:

### FlowOps — Sistema de Gestão de Projetos Ágil

O projeto FlowOps utiliza na prática conceitos aprendidos na unidade [Unidade3](https://github.com/rafaelbarros831/Engenharia_de_Requisitos_Turma_A/tree/main/Unidade3) e na unidade [Unidade4](https://github.com/rafaelbarros831/Engenharia_de_Requisitos_Turma_A/tree/main/Unidade4), como Engenharia de requisitos, necessidades do usuário e priorização de requisitos.

* [FlowOps](https://github.com/gabrielmarciano-dev/sistema-de-gestao-de-projetos-agil)

### Conecta

O projeto Conecta utiliza na prática os conteúdos aprendidos na unidade [Unidade5](https://github.com/rafaelbarros831/Engenharia_de_Requisitos_Turma_A/tree/main/Unidade5), servindo como referência complementar para os estudos de Elicitação de Requisitos e Modelagem de Sistemas.

* [Conecta](https://github.com/GabrielMarcianoarante/AulaEngRequisito)

Esses projetos funcionam como conexões entre os conceitos estudados na disciplina e suas aplicações práticas em projetos reais de software.

## Objetivos:

* Compreender os fundamentos da Engenharia de Requisitos;
* Identificar as necessidades dos stakeholders;
* Desenvolver e documentar requisitos de software;
* Compreender requisitos funcionais e não funcionais;
* Aplicar técnicas de priorização de requisitos;
* Estudar características de qualidade de software;
* Desenvolver modelos para representação de sistemas;
* Relacionar conceitos teóricos com aplicações práticas.
